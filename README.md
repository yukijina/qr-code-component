### What I learned

While building this QR code component, I practiced using semantic HTML to organize a page and CSS Flexbox to position the card and footer.

I also learned how sizing rules affect content. For example, `max-height` sets a limit on a card’s height, which can become a problem if text wraps onto more lines or is enlarged. Letting the card grow naturally helps it make room for its content.

### Continued development

I’d like to keep practicing responsive layouts and check how my pages look on narrow screens and when text is enlarged. I also want to continue improving accessibility, especially by writing useful alternative text for images.

### AI Collaboration

I used GitHub Copilot to review my HTML and CSS and to explain layout and sizing concepts in beginner-friendly terms. It helped me understand how a height limit could affect the card when text wraps or is enlarged. I used that explanation to decide how I want the card to behave.
